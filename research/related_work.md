# Related Work — Novelty Table for Abstaining Text-to-SQL via RL

Compiled 2026-11-04 from the research notes (`rl_text2sql.md`, `abstention_prior_work.md`). Everything was verified against the linked source on that date unless marked UNVERIFIED.

Terms used in the tables, once: **RL** = reinforcement learning (training a model by rewarding good outputs). **GRPO** = Group Relative Policy Optimization, the RL algorithm used by nearly all of these papers — it scores a group of sampled answers against each other instead of training a separate judge network; **Dr.GRPO** and **RLVR** (RL with verifiable rewards — the reward is computed by checking the answer, not by a learned judge) are variants. **Abstention** = the model declining to answer instead of guessing. **Risk–coverage (RC)** = the standard selective-prediction evaluation: a plot of the error rate among answered questions against the fraction of questions answered; **AURC** = area under that curve (one number for the whole trade-off; lower is better). **EX** = execution accuracy (a generated SQL query counts as correct only if running it returns the same result as the reference query). **RS(c)** = TrustSQL's penalty-based Reliability Score: +1 for a correct answer, 0 for abstaining on an answerable question, −c for a wrong answer or for answering an unanswerable question, +1 for correctly abstaining.

Column key: the flags column reads **RL / Abstention / Risk–coverage**, each Y (yes), N (no), or "~" (partial — explained in the row).

## Verdict

Is the exact combination — RL training with an explicit abstention reward, evaluated with risk–coverage curves, on a model of 4B parameters or smaller, in text-to-SQL — already published? **No, as of 2026-11-04.** Every pairwise combination exists, but no single paper holds all three ingredients in this domain at this scale. The nearest neighbors, in order: **BAR-SQL** (RL + abstention credit, 1.7B, text-to-SQL — but refusals are scored by text similarity rather than an explicit reward/penalty trade-off, there is no penalty parameter, no risk–coverage or RS(c) reporting, and evaluation is on a private enterprise benchmark with no Spider/BIRD numbers); **Reinforced Hesitation** (the exact +1/0/−λ reward on a ≤4B model, with a λ-sweep Pareto analysis a reviewer could call risk–coverage-adjacent — but on logic puzzles, with no SQL, no standard risk–coverage/AURC metrics, and no calibration guarantee); and **RLSR** (risk–coverage curves and AURC optimized directly by RL — but with no abstain action in training, at 7–8B, in QA/math). Rewarding Intellectual Humility holds the ≤4B + swept-abstain-reward cell on multiple-choice QA without risk–coverage. The smallest differentiating angle, if a reviewer treats these as prior art: an explicit structured abstain action trained with a penalty-swept ternary execution-grounded reward in text-to-SQL, reported with standard risk–coverage curves and TrustSQL's own RS(c) on public benchmarks, plus a distribution-free statistical guarantee (Learn-then-Test) and a schema-shift stress test — the last three elements appear in none of the near neighbors. Caveats on the negative claim: it is bounded by search coverage (high 2026 preprint volume; OpenReview not crawled; Abstain-R1's primary record, KARL's and TruthRL's experimental details not fully inspected), so an under-review or non-arXiv collision cannot be ruled out.
